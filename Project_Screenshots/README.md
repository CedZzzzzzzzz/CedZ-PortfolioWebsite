# Project screenshots

Add one PNG screenshot for each project using these exact filenames:

- `budget-tracker.png`
- `crime-detection-system.png`
- `ecobench.png`
- `portfolio-website.png`
- `quantis-f1.png`

Recommended export:

- 1600 × 900 pixels (16:9)
- PNG or PNG-8
- Under 500 KB per image when practical
- Crop browser chrome, private data, API keys, emails, and test credentials
- Show the most recognizable dashboard or result rather than a login screen

The portfolio displays a styled placeholder when a file is missing. As soon as a
matching file is added here, its project card displays it automatically.
